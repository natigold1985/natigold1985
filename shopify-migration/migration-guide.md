# מדריך מעבר לשופיפיי — יהודית גולד

תיקיה זו מכילה את כל מה שצריך כדי להעביר את האתר הנוכחי (HTML סטטי) לחנות
שופיפיי אמיתית. **חדשות טובות:** שופיפיי כבר פותרת באופן טבעי כמה מהדברים
שנאלצנו לבנות ידנית באתר הסטטי — בלי אפליקציות נוספות.

## קובצי התיקייה
- `products_import.csv` — כל 18 המוצרים, מחירים, תיאורים ותמונות, מוכן ל-Import.
- `content-pages.md` — תוכן מוכן להעתקה לעמודי "אודות", "טיפולים", "שאלות נפוצות" ולתקנון/פרטיות/נגישות.
- המדריך הזה.

---

## שלב 1: פתיחת חנות
1. הרשמה ב-shopify.com (יש תקופת ניסיון חינם).
2. בחירת ערכת נושא בעברית/RTL — **Dawn** (ברירת המחדל של שופיפיי) תומכת RTL
   דרך Settings → Languages, או אפשר לבחור ערכת נושא ייעודית מ-Theme Store
   שמתומחרת ל-RTL. יש להגדיר את שפת החנות לעברית.

## שלב 2: ייבוא המוצרים
1. Shopify Admin → Products → Import.
2. להעלות את `products_import.csv`.
3. **חשוב:** קובץ ה-CSV מפנה לתמונות המוצרים בכתובת
   `https://natigold1985.github.io/natigold1985/assets/img/...` (מהאתר הסטטי
   הנוכחי) — שופיפיי תמשוך את התמונות משם אוטומטית בזמן הייבוא, כל עוד האתר
   הזה עדיין באוויר ב-GitHub Pages. **לכן מומלץ לייבא לפני שסוגרים/מורידים את
   הריפו הזה.** אם תרצו, אפשר גם להוריד את `assets/img/products/` ולהעלות
   ידנית ב-Shopify → Content → Files, ואז לעדכן את עמודת Image Src בקובץ.
4. מוצר אחד — **בודי באדי (קרם לצלוליט)** — עדיין בלי תמונה אמיתית (זה נכון
   גם באתר הסטטי). יש להוסיף לו תמונה ידנית אחרי הייבוא.
5. אחרי הייבוא: לעבור על 2-3 מוצרים ולוודא שהתמונות, המחיר והתיאור נכנסו נכון.

## שלב 3: עמודי תוכן ומדיניות
לפי `content-pages.md`:
- Online Store → Pages: ליצור "אודות", "טיפולים במכון", "שאלות נפוצות".
- Settings → Policies: להדביק את התקנון ומדיניות הפרטיות (Shopify גם מציעה
  Generator אוטומטי שיוצר טיוטת בסיס — משלבים איתו את הטקסט שלנו).
- להוסיף עמוד "הצהרת נגישות" ולקשר אליו מהפוטר.
- **לפני פרסום בפועל: להשלים פרטי עוסק אמיתיים (שם/ח.פ./כתובת) ופרטי רכז/ת
  נגישות בכל המקומות המסומנים "הבהרה" — בליווי עורך/ת דין.**

## שלב 4: תשלומים — כאן שופיפיי פותרת את הבעיה המרכזית
באתר הסטטי אין ספק סליקה מחובר, ולכן הזמנה מסתיימת בוואטסאפ מול יהודית.
**בשופיפיי זה נפתר אוטומטית ברגע שמחברים ספק תשלום אמיתי:**
- **Shopify Payments** — הפתרון הכי פשוט, אבל זמין רק במדינות מסוימות; נכון
  לזמן כתיבת המדריך **ישראל לא ברשימת המדינות הנתמכות** — כדאי לבדוק שוב
  ב-Shopify Admin → Settings → Payments, כי הרשימה מתעדכנת.
- אם Shopify Payments לא זמין: לחבר ספק ישראלי דרך Shopify App Store —
  **Tranzila**, **Cardcom**, **PayPal**, **Grow**, **PayPlus** — לרוב יש
  אפליקציה רשמית או חיבור דרך "Alternative Payment Methods" ב-Settings →
  Payments. זה בדיוק אותו ספק שכבר תיעדנו כאפשרות ב-`js/config.js` של האתר
  הסטטי — עכשיו רק צריך לחבר אותו בתוך שופיפיי במקום לבנות צ'קאאוט בעצמנו.
- ברגע שספק תשלום מחובר, שופיפיי מפעילה צ'קאאוט מאובטח מלא (עמידה ב-PCI,
  התראות הונאה וכו') — אין יותר צורך בזרימת "שליחה בוואטסאפ" כפתרון זמני.

## שלב 5: תזכורת עגלה נטושה — כבר קיים בשופיפיי, בלי Make.com
באתר הסטטי בנינו webhook ידני ל-Make.com כדי לשלוח מייל תזכורת 4-5 שעות אחרי
נטישת עגלה, כי דפדפן לא יכול "לחכות" ככה. **בשופיפיי זה פיצ'ר מובנה וחינמי:**
1. Settings → Checkout → Abandoned checkout emails → להפעיל.
2. אפשר לקבוע את זמן השליחה (ברירת מחדל כ-10 שעות, ניתן לשנות באפליקציות
   ייעודיות כמו Klaviyo אם רוצים 4-5 שעות בדיוק ועיצוב מתקדם יותר).
3. שופיפיי גם עורכת את המייל בעצמה (לוגו, צבעים, תוכן העגלה) — אין צורך
   בתשתית ה-webhook שבנינו; היא הופכת ללא רלוונטית בשופיפיי.

## שלב 6: פופ-אפ 10% הנחה בהוספה לעגלה
שופיפיי לא כוללת "פופ-אפ ברגע הוספה לעגלה" מובנה. שתי אפשרויות:
- **הכי פשוט:** ליצור קוד הנחה אמיתי (Discount → Create discount → 10% off
  entire order, קוד `WELCOME10`) ולהציג אותו בבאנר/פס עליון קבוע ("קבלי 10%
  הנחה בקוד WELCOME10") — בלי אפליקציה נוספת.
- **כדי לשחזר בדיוק את הפופ-אפ עם טופס מייל + 2 תיבות הסכמה:** להתקין
  אפליקציית popup חינמית מה-App Store (למשל Privy, OptiMonk או Klaviyo
  Forms) — יש להן גרסאות חינמיות עם בונה פופ-אפים ויזואלי, כולל תמיכה
  בתיבות הסכמה מותאמות אישית.

## שלב 7: וואטסאפ
אפשר להשאיר קישור/כפתור וואטסאפ צף כמו באתר הנוכחי — יש אפליקציות חינמיות
ב-Shopify App Store ("WhatsApp Chat Button") שעושות בדיוק את זה, או פשוט
Custom Liquid section עם קישור ל-`https://wa.me/972547444478`.

## שלב 8: דומיין
אם ירכש דומיין (כמו judithgold.co.il) — חיבורו לשופיפיי פשוט בהרבה מ-GitHub
Pages: Settings → Domains → Connect existing domain, ושופיפיי מדריכה את
הגדרות ה-DNS צעד-אחר-צעד.

## שלב 9: SEO
- Shopify Admin → Online Store → Preferences: להעתיק את ה-meta description
  מ-`index.html` (כבר כתוב ומוכן בעברית).
- להעלות מחדש sitemap — שופיפיי יוצרת `sitemap.xml` אוטומטית לכל חנות.
- כדאי להגדיר 301 redirect מכתובת ה-GitHub Pages הישנה לחנות החדשה, כדי לא
  לאבד קישורים/דירוג אם משהו כבר קישר לאתר הסטטי.

## סיכום: מה שבנינו באתר הסטטי מול הפתרון בשופיפיי

| מה שבנינו ידנית | הפתרון בשופיפיי |
|---|---|
| עגלת קניות ב-localStorage | מובנה בשופיפיי |
| דף סליקה + fallback וואטסאפ (כי אין ספק) | צ'קאאוט מאובטח אמיתי ברגע שמחברים ספק תשלום |
| Webhook ל-Make.com לתזכורת עגלה נטושה | Abandoned checkout emails — מובנה וחינמי |
| פופ-אפ 10% + 2 תיבות הסכמה | קוד הנחה אמיתי + (אופציונלי) אפליקציית פופ-אפ |
| מחירון ותיאורי מוצרים ב-`products.js` | מיובא ישירות מה-CSV המצורף |
| תקנון/פרטיות/נגישות ב-HTML | מודבק ל-Settings → Policies / עמודים |
